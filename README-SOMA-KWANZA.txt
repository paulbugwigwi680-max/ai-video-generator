BUGWIGWI - sasisho (sauti ya AI, picha inayoongea, Google, Cloudinary)

1. Fungua zip hii kwenye kompyuta.
2. GitHub > repo ai-video-generator > Add file > Upload files.
3. Buruta folda: app, components, lib (zinaungana na zilizopo).
4. USIPAKIE globals-append.css. Fungua, nakili maudhui yote, bandika MWISHONI mwa app/globals.css.
5. Commit changes. Subiri Vercel iwe Ready.

GOOGLE SEARCH CONSOLE (bila Vercel):
a. search.google.com/search-console > Add property > URL prefix > weka anwani ya tovuti.
b. Chagua njia ya "HTML file". Pakua faili wanalokupa (jina kama google1234abcd.html).
c. GitHub > Add file > Create new file > kwenye jina andika:  public/google1234abcd.html
   (badilisha jina liwe sawa na lile la Google). Kwenye maudhui andika mstari mmoja:
   google-site-verification: google1234abcd.html
d. Commit. Subiri Ready. Fungua https://TOVUTI-YAKO/google1234abcd.html kuona maudhui.
e. Rudi Search Console > Verify. Kisha Sitemaps > andika sitemap.xml > Submit.
